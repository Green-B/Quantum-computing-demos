# Quantum computing demos

These are example applications of quantum algorithms in Qiskit and PennyLane. Generally I will aim to make them reasonably accessible at the physics graduate student level using interactive notebooks.

Demos so far:
- VQE_TFIM: Implementation of the variational quantum eigensolver in Qiskit applied to the 1D transverse field Ising model, comparing mean-field and correlated anstazes.
